# ADR-0005 — Definition of Done

**Status:** Accepted (tham chiếu quy trình)  
**Date:** 2026-06-08  
**Deciders:** Tech Lead

> [!NOTE]
> Checklist quy trình dưới đây phản ánh quy ước làm việc dự kiến. Lưu ý thực tế: **CI (GitHub Actions) chỉ build/test, không tự deploy**; deploy production do **Railway** thực hiện khi push nhánh `dev`.

## Checklist bắt buộc

Task chỉ được chuyển sang **Done** khi TẤT CẢ điều sau đều đúng:

- [ ] Code implement đúng Acceptance Criteria trong `/tasks/ASS-XXX.md`
- [ ] Unit tests viết xong và pass (`npm test` — không có test đỏ)
- [ ] ESLint: `npm run lint` — không còn error (warning OK)
- [ ] Prettier: `npm run format` — không có diff
- [ ] `/specs/api-contracts.md` hoặc Spec liên quan đã cập nhật (nếu có thay đổi interface)
- [ ] Pull Request đã được tạo với title format `[ASS-XXX] Tên task`
- [ ] PR description link đến `/tasks/ASS-XXX.md`
- [ ] CI/CD pipeline: tất cả checks green (lint + test + build)
- [ ] Ít nhất 1 thành viên khác đã Approved PR
- [ ] Tech Lead approve final (cho các task ảnh hưởng architecture hoặc AI/API)
- [ ] Staging deploy thành công (không manual hotfix)

## Không phải Done

> "Code chạy được trên máy mình" ≠ Done.

- Test pass trên local nhưng CI fail → **NOT Done**
- PR chưa có Approved → **NOT Done**
- Spec/Contract thay đổi nhưng file chưa cập nhật → **NOT Done**
- Console error trên staging → **NOT Done**

## Bug severity

| Mức | Mô tả | SLA fix |
|-----|-------|---------|
| P0 Critical | App crash, data loss, auth bypass | < 4 giờ |
| P1 High | Feature broken, không có workaround | < 1 ngày |
| P2 Medium | Feature broken, có workaround | < 3 ngày |
| P3 Low | UI glitch, cosmetic | Sprint tiếp theo |
